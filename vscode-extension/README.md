# iSheild

Your development environment should adapt to your day — not fight against it.

Ever opened VS Code late at night and been hit by a bright, cold interface?

Or started coding in the morning and found yourself staring at a dark developer setup?

**iSheild automatically changes your VS Code theme based on the time of day.**

## 🌅 Morning

A warm, light interface designed for the beginning of your day.

## ☀️ Day

A balanced developer theme for focused daytime work.

## 🌙 Night

A deeper, calmer theme designed for late-night coding.

---

## ✨ How It Works

Install iSheild once and let it work automatically.
